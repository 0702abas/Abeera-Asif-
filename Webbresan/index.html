Så fungerar webben-HASEERA

1. Jag skriver in adressen

Adressen består av flera delar. Protkoll, namn och domän + etc

  1. Protokoll
  2. adress
  3. Domän
  4. sökväg
  5. Variabler

2. Datorn slår upp namnet

Antingen finns det i webbläsaren, på datorn eller på server.

3 Webbläsaren frågar serven

Webbläsaren skickar iväg frågan till servens adress.

4. Serven svarar.

Först med kod. 200 om ok. 404 om inte finns. Sen kommer HTML-Koiden
